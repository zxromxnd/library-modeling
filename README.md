# Моделювання бібліотеки

Навчальний проєкт з моделювання невеликої бібліотеки паперових книг.

Лабораторна робота 1 присвячена домену та ER-моделі. Матеріали роботи готуються у гілці `lab1-er` для подальшого Pull Request до `main`.

Робота виконується з використанням ШІ та перевіркою рішень студентом.
