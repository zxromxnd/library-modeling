## Позначення та обов’язковість

`PK` — первинний ключ, `FK` — зовнішній ключ; `int` — ціле число, `string` — текст, `date` — календарна дата без часу. Коментар «необов'язкове» позначає допустиму відсутність значення. Усі інші атрибути обов’язкові; обов’язковий текст непорожній.

Кінці зв’язків читаються так: `||` — рівно один, `o{` / `}o` — від нуля до багатьох, `|{` / `}|` — від одного до багатьох. Позначка біля сутності описує кількість її екземплярів для одного екземпляра протилежної сутності. Пунктир позначає неідентифікувальний зв’язок: пов’язані сутності мають власні PK, а FK не входять до їхніх PK. Пунктир не означає необов’язковість — мінімум задається позначками на кінцях.

| Зв’язок | В обох напрямках |
|---|---|
| Автор — Видання | Автор має 1..* видань; видання має 0..* зазначених авторів. |
| Видання — Примірник | Видання має 1..* примірників; примірник належить рівно одному виданню. |
| Примірник — Видача | Примірник має 0..* видач за історію; видача стосується рівно одного примірника. |
| Читач — Видача | Читач має 0..* видач за історію; видача стосується рівно одного читача. |

## Обмеження поза графічною нотацією

1. Усі PK — додатні цілі числа, унікальні в межах своєї сутності. FK також цілі та посилаються на наявні записи: `Примірник.edition_id → Видання.edition_id`, `Видача.reader_id → Читач.reader_id`, `Видача.inventory_number → Примірник.inventory_number`.
2. Щонайменше одне з `Автор.given_name`, `Автор.family_name`, `Автор.pen_name` непорожнє. Псевдонім один або відсутній. Невідоме авторство видання не створює вигаданий запис автора.
3. Невідомі рік і видавництво залишаються без значення; відомий рік більший за нуль. Невідомі відомості не замінюються вигаданим роком чи текстом «невідомо». Телефон — обов’язковий непорожній текст, без вимоги унікальності.
4. `due_on >= issued_on`; за наявності `returned_on >= issued_on`. Повернення в день видачі допустиме. `returned_on > due_on` означає прострочення, але не перешкоджає фіксації повернення. Повернення у планову дату своєчасне.
5. Видача незавершена, якщо `returned_on` відсутня. Для примірника одночасно допускається не більше однієї такої видачі. Зв’язок 0..* описує всю історію, а не кількість одночасних видач. Сама ER-діаграма не виконує перевірок даних.
6. Повернення заповнює дату в наявній видачі, не видаляючи її. Наступна видача того самого примірника створює новий запис. Три примірники одному читачеві — три незалежні записи; повернення одного не завершує інші.
7. Читач може мати кілька незавершених видач різних примірників без числового ліміту. Реєстрація може зберігатися до першої видачі. Виданий читачеві примірник залишається обліковуваним примірником свого видання.
8. Доступність визначається відсутністю незавершеної видачі й не зберігається окремим атрибутом. Ремонт, втрата, списання та інші процеси поза S1 не враховуються. Видача має власні дати; технічної сполучної таблиці авторів і видань та окремої сутності повернення немає.
