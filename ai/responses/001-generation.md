# Відповідь на запит 001 — перша ER-модель

Первинний результат підготовлено для спільного аудиту зі студентом. Нижче збережено фактичний перебіг генерації та технічні спроби.

## Збережено

- Запит погоджено та закомічено: `b76a4d5`.
- Прочитано `spec.md` з коміту `b15e6c40a62991efa3e7f3dfef5efca331994dd6`; специфікацію не змінено.
- Створено [перший декларативний текст](../../model/library-er.mmd), [пояснення](../../model/README.md) та конфігурацію рендера.
- Технічний підрахунок: 5 сутностей, 21 атрибут, 4 зв’язки, 5 PK, 3 FK. Це не замінює спільного предметного аудиту.

## Фактичні спроби рендера

1. Установлення Mermaid CLI через npm з типовим кешем завершилося помилкою доступу `EPERM` до каталогу кешу.
2. Повторення з кешем у робочій папці дійшло до інсталяційного скрипту Puppeteer, який завершився помилкою доступу Windows.
3. Установлення через наявний службовий Node.js з `--ignore-scripts` успішне. У робочій папці встановлено Mermaid CLI 12.0.0, Mermaid 12.0.0 та Puppeteer 25.12.0. Для рендера налаштовано наявний Microsoft Edge.
4. Перша команда рендера відхилила параметр `-w` повідомленням `unknown option '-w'`. SVG не створено. Наступний крок — прочитати довідку встановленої CLI й скоригувати параметри запуску, не змінюючи вимоги або модель для обходу помилки.

5. Після перевірки `--help` параметр `-w` прибрано. CLI прийняла команду, але запуск браузера завершився тайм-аутом 30 секунд.
6. Спроба з окремим профілем у робочій папці та каналом `pipe` показала помилки запуску GPU-процесу Edge й завершилася тайм-аутом. Модель і специфікацію для обходу цих помилок не змінювали.
7. Mermaid 12.0.0 запущено на локальній сторінці у вбудованому браузері. Метод `mermaid.render` успішно побудував SVG з того самого `.mmd`; результат збережено кнопкою сторінки. [Скрипт локального рендера](../../tools/render_server.py) та інструкція повторення додані до репозиторію.

## Результат і технічна перевірка

- [SVG-діаграма](../../model/library-er.svg) створена; XML структурно коректний.
- Візуально оглянуто повну діаграму: п’ять сутностей, усі атрибути й чотири зв’язки видимі; обрізаних підписів і перетинів ліній не виявлено.
- `spec.md` і декларативна модель не змінені під час налагодження рендера.
- Обмеження, які не виражаються кардинальностями, наведені в `model/README.md`, зокрема одна незавершена видача примірника та правила дат.

## Наступний етап

На момент генерації предметний аудит, ADR та DEFENSE ще були попереду. Наступні фактичні перевірки збережено в [журналі аудиту](../audit.md); актуальний стан — у [README](../../README.md). Технічні помилки запуску рендера не видаються за три предметні розбіжності моделі зі специфікацією.
