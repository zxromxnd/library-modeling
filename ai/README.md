# Матеріали роботи з ШІ

## Підготовка вимог

- [Журнал рішень](decisions.md) — 27 обговорень, альтернативи, заперечення та посилання на специфікацію.
- [Відредагований діалог](preparation-dialogue.md) — змістовне обговорення предметної області. Студент перевірив документ і погодив його зміст.
- [Специфікація](../spec.md) — погоджені вимоги та критерії прийняття до генерації моделі.

## Подальша фіксація

Для генерації зберігатимемо точний запит українською та ідентифікатор коміту специфікації, а для перевірки — фактичний результат, фідбек, уточнення вимог і коміт виправлення. Ці матеріали додаватимуться під час виконання, а не відтворюватимуться як вигадана історія.

Повний дослівний архів підготовчих повідомлень ще не додано; наявні редакційні документи не позначаються як такий архів. Аудит першої ER-моделі ще не проводився.
