# Матеріали роботи з ШІ

## Підготовка вимог

- [Журнал рішень](decisions.md) — 27 обговорень, альтернативи, заперечення та посилання на специфікацію.
- [Відредагований діалог](preparation-dialogue.md) — змістовне обговорення предметної області. Студент перевірив документ і погодив його зміст.
- [Специфікація](../spec.md) — погоджені вимоги та критерії прийняття до генерації моделі.

## Генерація та аудит

- [Точний запит 001](prompts/001-generate-er.md) — погоджений і зафіксований у `b76a4d5` до генерації; посилається на специфікацію `b15e6c4`.
- [Результат генерації](responses/001-generation.md) — артефакти, технічні спроби та перевірка рендера; модель у `9a114ae`, рендер у `7388052`.
- [Аудит A01–A08](audit.md) — редакційні підсумки фактичного предметного обговорення, з розмежуванням відповідей студента та пояснень ШІ.

Три предметні розбіжності не виявлено. Запитів повторної генерації, уточнень spec для виправлень та комітів виправлення моделі наразі немає. Якщо розбіжність буде знайдено, її фідбек пов’язуватиметься із запитом, пунктом spec, уточненням критеріїв та комітом виправлення.

## Повнота сліду

Повний дослівний архів підготовчих повідомлень ще не додано; редакційні документи його не замінюють. Точний запит генерації збережений, але це саме по собі не закриває вимогу повного сліду всієї підготовки. Організаційні розмови не включено до предметного діалогу за проханням студента. Наявні документи не позначаються як повний архів.
